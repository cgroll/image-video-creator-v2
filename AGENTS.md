# AGENTS.md

Operational notes for working in this repo. See `README.md` for the full
pipeline explanation and setup instructions — this file is the short list of
things that are easy to get wrong or miss.

## After editing storyline.yaml

Regenerate the manual-preview data:

```bash
uv run python scripts/generate_deck_scenes.py <project-name>
```

`projects/<name>/deck-scenes.js` is generated by this script — never
hand-edit it.

## Previewing without the full pipeline

Don't run `narrate`/`record`/`build` just to check a visual change — it's
slow and, for the `google` TTS provider, costs money per run. Regenerate
`deck-scenes.js` (above) and open `projects/<name>/deck.html?manual=1` in a
browser instead: prev/next buttons and a dot per scene, no narration or
recording involved.

## Discovering what a deck.html supports

`visual.kind` / `visual.style` in `storyline.yaml` aren't validated by the
framework — they're whatever the project's `deck.html` happens to implement.
Before inventing a new one, check the `RENDERERS` object (for `text_slide`
styles) and the `renderScene` / `ANIM_GROUP_FN` dispatch (for
`animation_step` groups) in `deck.html`, or look at scenes already used in
`storyline.yaml` for working examples.

## Output directories

`projects/*/output/` (narration audio, recorded video, final mp4) is
generated and gitignored. Never commit it.

## TTS providers

Check `project.yaml`'s `tts.provider` before assuming which applies:

- `google`: no GPU needed; requires Application Default Credentials.
- `qwen_voice_clone`: needs an NVIDIA GPU (`cuda:0`).
